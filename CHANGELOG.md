# Changelog

## 5.0.1
- A finished cat no longer says MEOW when you are already looking at its conversation's window.
- README with pictures.

## 5.0.0
- Installer: per-user Setup.exe (no admin), Start-menu shortcut, Start with Windows, uninstaller.
- Tray menu: Start with Windows, Check for updates, About.
- Cats roam between monitors, cats from the same project play tag, and cats sprint after a long yarn throw.
- App icon.
- Cats for Codex, Copilot, Cursor and Gemini sessions through hooks; Coding tools menu to install and remove them.
- Per-project looks (coats, collars, personality, favourite toy) saved between runs; right-click customization.
- Tray icon replaces the taskbar dock.
- Thrown yarn ball bounces and spins; cats and the ball follow the pointer when carried; new sleeping poses.
- Hover card above a cat: project, model, what it is doing and for how long, edits/errors, sub-agents, context fill, API trouble. Tray → "Hover cards" (on by default; off = the old tooltip).
- Optional chime when a cat finishes or starts waiting for you. Tray → "Sounds" (off by default). Quiet projects never chime.
